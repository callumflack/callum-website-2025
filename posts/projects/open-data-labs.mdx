[Open Data Labs](https://www.opendatalabs.com/) is the company. [Vana](https://docs.vana.org/) is the protocol.

Vana is an open protocol for private, user-owned data — a peer-to-peer network where access, encryption, and payment are first-class, on-chain concerns. A user owns their data and grants access on their own terms. Builders request it from the user's Personal Server. The protocol is designed to work without ODL: the SDK path uses only permissionless surfaces.

ODL operates the convenience layer on top. In the [stack](https://docs.vana.org/), that is the Data Pipe (public data in) and the Context Gateway (OAuth, USD billing for builders and enterprises). Commercially, ODL is the AI training-data company around that protocol: a user context API and a marketplace for consented datasets. Same problem as the [2022–24 Vana stint](/vana) — personal data in the age of LLM agents — different layer. I came back in mid-2025 as UX designer and web engineer.
