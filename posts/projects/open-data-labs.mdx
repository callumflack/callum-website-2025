I returned to Vana in mid-2025 as UX designer and web engineer. [Vana](https://vana.org/) is an open protocol for private, user-owned data. Vana's sister entity, [Open Data Labs (ODL)](https://www.opendatalabs.com/), is the company around the protocol. So my work bleeds across both.

## ODL Website

I designed the ODL website with creative director [Ciaran Moore](https://www.cicici.ci/). Originally it was built externally, then I rebuilt it in 2 days. By owning the content in code instead of a CMS, the team has since iterated on the design and content with much greater tempo using Claude Code.

## ODL Playground

I designed and built the ODL Playground: a shop window for private, user-authorized data you can’t scrape. My favourite part of it is the tailored typography fade and swap on scroll, using CSS only. Visit [ODL Playground](https://playground.opendatalabs.xyz/).

## PDPP brand identity

I designed the identity for [PDPP](https://pdpp.dev/), an open protocol for scoped access to personal data so apps and agents can use purchases, messages, and workouts without a grab. Visit [PDPP](https://pdpp.dev/).
