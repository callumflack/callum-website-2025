I returned to [Vana](https://vana.org/) in mid-2025 as UX designer and web engineer. The first stint was [2022–24](/vana) where we created Portrait, an AI image generator before ChatGPT. In my second stint, we continue to further our goal of securing personal data, an ever-important problem in light of recent LLM-agent hacking episodes. Same company, different maze, with a mission as important as ever.

## ODL Website

I designed and built the ODL website in 2 days. The result is a much more performant experience. With the code in place, the team has since iterated on the design and content with ease using Claude Code — no need for the obstacle of a CMS with a good codebase organised around a robust design system. Visit [Open Data Labs](https://www.opendatalabs.com/).
