I returned to [Vana](https://vana.org/) in mid-2025 as UX designer and web engineer. The first stint was [2022–24](/vana) where we created Portrait, an AI image generator before ChatGPT.

## Vana App

In my role as UX designer and web engineer, I would take ideas form the founders, sketch to confirm understaning then shift into code as fast as possible. Most UI design occurs in code to increase velocity. A good example of this is the [Vana App](https://app.vana.org) across web and MacOS desktop, were I designed and built the onboarding in code based on the design system I'd previously created.
